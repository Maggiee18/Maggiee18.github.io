      Definitions used on this page
      Unique registration
      One record per phone fingerprint. A second signup with the same number is refused and never counted.
      Duplicate registration
      A signup attempt whose phone fingerprint already exists. Shown to the student as “already registered”, not stored.
      Acquisition source
      Exactly one per registration, so sources add up to the total. Rule: a valid ambassador code means Ambassador; a valid student code means Referral; with no code, the student's own answer to “where did you first hear” decides.
      Referral attribution
      A registration that used any valid code. Credit goes to the code owner. Self referral is blocked.
      Active ambassador
      An ambassador whose code brought at least one registration.
      Qualified registration
      Not used yet. In a real run it would mean a 2026 or 2027 graduate who confirms the joining message.
      Forecast
      Average of the last two days, times days left, shown as a range of ±25%. It is an estimate, not a result.
