# Sai Meghana Annepu: portfolio

My personal site. Pick a skill on the left and the page draws a line to every project where I've used it.

Plain HTML, CSS and JavaScript, no build step. Hosted on GitHub Pages.

## Run locally

Open `index.html` in a browser.

## Update

* Projects and skills live at the top of `app.js` (the `SKILLS` and `PROJECTS` arrays).
* Replace `assets/Sai_Meghana_Annepu_Resume.pdf` to update the resume download.
